# Nordblick Kiel – Weather & News

A simple website providing current weather information and news for Kiel, Germany.

## 🌦️ About

Nordblick Kiel gives visitors a quick overview of the current weather and relevant news from Kiel and the surrounding area.

## ✨ Features

- Current weather information
- Local news from Kiel and the surrounding area
- Clean and modern design
- Mobile-friendly layout
- Easy to access through the web

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
